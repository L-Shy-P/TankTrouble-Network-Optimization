## ⚠️ Это userscript, а не расширение браузера

Сначала установите менеджер userscript'ов **Tampermonkey**. Не используйте `chrome://extensions` / «Загрузить распакованное расширение» — файлом `.user.js` управляет Tampermonkey, это не расширение браузера. Если на экране появился код — вы попали не туда, вернитесь к этой инструкции.

## Способ A — перетащите скачанный файл в Dashboard Tampermonkey (рекомендуется, проще всего)

### Шаг 1 (только один раз) — установите Tampermonkey

Chrome/Edge: откройте [Chrome Web Store](https://chromewebstore.google.com/detail/tampermonkey/dhdgffkkebhmkfjojejmpbldmpobfkfo) → **Добавить в Chrome**. Firefox: откройте [addons.mozilla.org](https://addons.mozilla.org/firefox/addon/tampermonkey/) → **Добавить в Firefox**.

Если после установки значка Tampermonkey нет на панели: нажмите кнопку **пазла / расширений** справа вверху и **закрепите (Pin)** Tampermonkey.

### Шаг 2 — скачайте файл скрипта

Нажмите **[⬇ Download](https://github.com/L-Shy-P/TankTrouble-Network-Optimization/raw/main/tanktrouble-netlab.install.user.js)** (или откройте ссылку ниже): браузер сохранит файл в папку **«Загрузки»** под именем `tanktrouble-netlab.install.user.js`.

**Не переименовывайте, не распаковывайте и не редактируйте его** — это обычный текстовый скрипт.

```
https://github.com/L-Shy-P/TankTrouble-Network-Optimization/raw/main/tanktrouble-netlab.install.user.js
```

### Шаг 3 — откройте **Dashboard** Tampermonkey (именно здесь большинство застревает)

Нажмите **значок Tampermonkey** на панели браузера → в открывшемся меню выберите **Dashboard** (в русском интерфейсе — **Панель управления**).

- Не нашли значок: нажмите кнопку **пазла / расширений**, затем Tampermonkey.
- ⚠️ Пункт «**Добавить новый скрипт**» в этом меню открывает **редактор**, а не страницу установки. Нужен именно **Dashboard** (в китайском интерфейсе — «管理面板»).
- Если вы уже на другой странице Tampermonkey, нажмите **Installed scripts / Установленные скрипты** в левой панели, чтобы вернуться к списку.

### Шаг 4 — перетащите файл

Оставьте открытой **страницу списка Dashboard** и перетащите `tanktrouble-netlab.install.user.js` из папки **«Загрузки» прямо на страницу Dashboard** → появится страница установки Tampermonkey (тёмная, с именем скрипта "TankTrouble Network Optimization", версией и кнопкой **Install**) → нажмите **Install**.

- Если перетаскивание не работает: **Dashboard → Utilities / Утилиты → Install from URL**, вставьте ту же ссылку для скачивания и нажмите **Install**.
- Можно также сразу нажать ссылку установки в один клик (сохранена ниже как **Способ B**): с установленным Tampermonkey сразу откроется страница установки. Если вместо неё видите целую страницу кода, начинающегося с `// ==UserScript==`, значит клик не дошёл до Tampermonkey → вернитесь к описанному выше перетаскиванию.

### Шаг 5 — откройте игру

Откройте <https://tanktrouble.com/game> → жёстко обновите страницу через **Ctrl + F5** → слева вверху появится панель или шар. Если его не видно, нажмите **Ctrl + Shift + L** — возможно, он скрыт.

### Самопроверка (три пункта)

① В списке скриптов **Dashboard** есть "TankTrouble Network Optimization", переключатель в положении **ON**; ② на странице `tanktrouble.com` на значке Tampermonkey появляется числовой бейдж **1**; ③ нажмите **F12 → Console** — должна появиться строка `[TT NetLab vX.Y.Z] loaded...`.

Если Tampermonkey уже установлен, нажмите кнопку (или ссылку ниже): Tampermonkey сразу откроет свою страницу установки — тёмную страницу с именем скрипта "TankTrouble Network Optimization", версией и кнопкой **Install**; только после нажатия **Install** скрипт установится. ## Способ C — установка из скачанного ZIP (офлайн)

Если вы уже умеете устанавливать перетаскиванием, **Способа A достаточно — ZIP скачивать не нужно**. ZIP нужен, только если хотите сохранить весь репозиторий офлайн.

1. **Скачайте ZIP**

   На [странице GitHub](https://github.com/L-Shy-P/TankTrouble-Network-Optimization) нажмите **Code → Download ZIP**.
2. **Распакуйте**

   Распакуйте ZIP в обычную папку.
3. **Убедитесь, что Tampermonkey установлен**

   Если нет, вернитесь к шагу 1 способа A. Не используйте `chrome://extensions`.
4. **Загрузите userscript**

   Нажмите значок Tampermonkey → **Dashboard**, оставьте открытой страницу списка, перетащите `tanktrouble-netlab.install.user.js` из распакованной папки на страницу Dashboard и нажмите **Install**. Если перетаскивание не работает, используйте **Dashboard → Utilities → Install from URL**.
5. **Обновите страницу игры**

   Откройте <https://tanktrouble.com/game> (обновите, если уже открыто). Слева вверху появится шар; нажмите на него, чтобы раскрыть, и пользуйтесь.

`tanktrouble-netlab.user.js` — то же содержимое; `install.user.js` — копия с BOM для перетаскивания.

## Горячие клавиши

| Key | |
|---|---|
| `Ctrl+Shift+S` | включить/выключить оптимизацию (живое A/B) |
| `Ctrl+Shift+L` | скрыть / показать HUD |
| `Ctrl+Shift+E` | экспорт диагностического отчёта (и в буфер обмена) |
| `Ctrl+Shift+P` | протестировать 7 регионов и построить рейтинг |

Кнопка **⚡** в панели делает то же, что `Ctrl+Shift+S`. В панели можно выбрать один из **11 языков**; язык, переключатель и позиция шара хранятся в `localStorage`.

## FAQ для новичков (если запутались — сюда)

- **Это расширение Chrome? Добавлять в chrome://extensions?** — Нет, это userscript. Сначала установите Tampermonkey, а скрипт ставьте внутри него. «Загрузить распакованное расширение» не используется.
- **Tampermonkey выглядит подозрительно.** — Это самый популярный менеджер userscript'ов для Chrome/Edge/Firefox, ставится из официальных магазинов (tampermonkey.net). Проект открыт на GitHub, сервер/VPN/настройка сети не нужны.
- **Скачал ZIP — перетаскивать всю папку?** — Нет. В способе A ZIP вообще не нужен: скачайте один файл `tanktrouble-netlab.install.user.js` (шаг 2) и перетащите из папки «Загрузки» в панель Tampermonkey только этот файл. Целая папка не является скриптом и не установится.
- **Где находится панель (Dashboard) Tampermonkey и как её открыть?** — Нажмите **значок Tampermonkey** на панели браузера → **Dashboard** (Панель управления). Нет значка? Нажмите кнопку пазла/расширений и закрепите Tampermonkey. Если вы уже на другой странице Tampermonkey, нажмите **Installed scripts / Установленные скрипты** слева, чтобы вернуться к списку. ⚠️ Не используйте пункт «**Добавить новый скрипт**» — он открывает редактор, а не страницу установки.
- **Я нажал «Добавить новый скрипт» и попал в редактор — это и есть установка?** — Нет. «Добавить новый скрипт» открывает **редактор** Tampermonkey для написания скриптов, а не установку этого скрипта. Установка начинается со страницы списка **Dashboard** («Установленные скрипты»): перетащите туда скачанный `tanktrouble-netlab.install.user.js` или используйте **Dashboard → Utilities / Утилиты → Install from URL** и вставьте `https://github.com/L-Shy-P/TankTrouble-Network-Optimization/raw/main/tanktrouble-netlab.install.user.js`.
- **Ссылка для скачивания открывает страницу с кодом / Chrome пишет, что нельзя установить с этого сайта.** — Для способа A это нормально — эта ссылка только сохраняет файл (проверьте папку «Загрузки»: `tanktrouble-netlab.install.user.js`). Затем перетащите файл на страницу списка **Dashboard** Tampermonkey. Если файл не скачался, нажмите на ссылку правой кнопкой → «Сохранить ссылку как…» или используйте **Dashboard → Utilities → Install from URL** с той же ссылкой.
- **Перетаскиваю файл, ничего не происходит.** — Бросать нужно прямо на страницу списка **Dashboard** Tampermonkey (не на chrome://extensions и не на обычную страницу), оставив её открытой и поверх остальных. Если перетаскивание блокируется, используйте **Dashboard → Utilities → Install from URL**.
- **Установил, но в игре ничего нет.** — Обновите страницу игры Ctrl+F5, проверьте, что скрипт включён в панели, нажмите Ctrl+Shift+L для HUD. Страницу, открытую до установки, нужно обновить.
- **Оставлять ZIP/папку после установки?** — Нет. Скрипт уже в Tampermonkey; ZIP можно удалить. Обновление — через Tampermonkey или повторную установку raw-ссылки.
- **В Tampermonkey есть «Импорт из файла»/«Add file» — туда загружать?** — Нет, эта кнопка для резервных `.zip` Tampermonkey. Для установки скрипта используйте Панель → Утилиты → Установить из URL или перетащите один файл `.user.js` в панель.
- **Нужно переименовывать, редактировать или распаковывать `.user.js`?** — Нет, используйте файл как есть. Это и есть текст скрипта. Не кладите его в `chrome://extensions` и не загружайте целую папку.
- **Я нажал ссылку установки в один клик (способ B) — точно ли она установилась?** — Если всё сработало, **Tampermonkey открывает свою страницу установки**: тёмная страница с названием скрипта "TankTrouble Network Optimization", номером версии и кнопкой **Install** — установка происходит только после нажатия **Install**. Если вы видите целую страницу кода (начинающегося с `// ==UserScript==`) или файл просто скачался, значит клик не дошёл до Tampermonkey: вернитесь к **способу A** и перетащите скачанный `tanktrouble-netlab.install.user.js` на страницу **Dashboard**, либо используйте **Dashboard → Utilities → Install from URL**.
- **Как убедиться, что скрипт действительно установлен и работает?** — Три проверки: ① в списке скриптов **Dashboard** Tampermonkey виден «TankTrouble Network Optimization», а переключатель стоит в **ON**; ② на странице `tanktrouble.com` на значке Tampermonkey появляется цифровой бейдж (**1**); ③ нажмите **F12 → Console** — должна появиться строка `[TT NetLab vX.Y.Z] loaded...`. Если пункта ③ нет: сначала перезагрузите страницу через **Ctrl+F5**; если строки всё ещё нет, скрипт отключён или установлен частично (**переустановите** его; файл должен начинаться с 1-й строки `// ==UserScript==`, копирование с середины вроде `(function () {` не работает).

## Если что-то не работает

- **Ничего не появилось** — Проверьте, что URL совпадает с `*://*.tanktrouble.com/*` и скрипт включён, затем `Ctrl+F5`.
- **Панель исчезла** — Нажмите `Ctrl+Shift+L`. Позиция и свёрнутость запоминаются.
- **Всё ещё лагает** — Это ваша линия. Экспортируйте отчёт (`Ctrl+Shift+E`) и сравните регионы.
